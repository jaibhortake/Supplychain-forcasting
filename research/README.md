# Original proof of concept

The internship PoC this project grew out of, kept for reference.

| File | What it is |
|---|---|
| `poc_v1.ipynb` | First version: Excel context loader, CrewAI agents on Ollama (llama3.2) |
| `poc_final.ipynb` | Final version: multiplier logic, evaluation (MAPE/RMSE), Gradio demo UI |
| `poc_documentation.pdf` | Write-up of the PoC design |

These notebooks are **not** used by the app. The production code lives in `backend/` and `frontend/`. See the main
README's *Background* section for what changed and why.
